# DATHEON-TASK3-Telco-Churn-Dashboard
Telco Customer Churn Dashboard in Power BI - DATHEON TASK3
## DATHEON TASK3 - Telco Customer Churn Dashboard

Goal was sales-style dashboard, but dataset is Telco Churn. So I adapted it - TotalCharges as Revenue, Tenure as Time, InternetService / Contract as Segment, PaymentMethod as Treemap.

Key Insight: Month-to-month contract customers churn the most, 2-year contract gives highest revenue, and 4+ Years tenure customers give highest revenue.

Tools: Power BI, DAX, Excel
Pages: 1. Executive Overview  2. Churn Analysis  3. Revenue & Tenure
